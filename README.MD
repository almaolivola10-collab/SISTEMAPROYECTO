## Descripción del Proyecto

Esta actividad aborda el modelado de entidades del mundo real (sensores, módulos de hardware, usuarios, etc.) mediante **estructuras de datos (`struct`)** en C++. Se ejercita el control de lectura y modificación de sus campos por referencia mediante **punteros** y el **operador flecha (`->`)**, sentando las bases lógicas para la arquitectura de software del **Proyecto Integrador Anual (P.I.A.)** para la Expotécnica.
